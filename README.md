# 🐱 喵喵倖存者 Meow Survivors

一款免安裝的單檔網頁遊戲：貓咪主角對抗鼠群、野狗幫與機器人大軍，
自動攻擊、走位生存、升級三選一、擊敗 Boss 過關！

- **遊戲檔案**：`index.html`（單一檔案，含全部程式與音效，免安裝、離線可玩）
- **類型**：倖存者玩法（自動攻擊割草）＋ 進化成長 ＋ 金幣商店
- **平台**：電腦（鍵盤）、手機（觸控）
- **語言**：繁體中文

---

## 🎮 如何開始玩

### 電腦
1. 對著 `index.html` **按兩下**（用 Chrome、Edge 或 Firefox 開啟）
2. 建議按右上角的 ⛶ 進入全螢幕

### 手機
1. 把 `index.html` 傳到手機（LINE 傳給自己、雲端硬碟、USB 都可以）
2. 用瀏覽器開啟檔案（iPhone 用「檔案」App 點開；Android 用檔案管理器點開）
3. 橫向遊玩體驗最佳

### 分享給學生
- 直接傳 `index.html` 一個檔案即可（LINE、Google 雲端硬碟、教學平台都行）
- 或上傳到任何網頁空間／學校網站，用網址開啟
- 存檔（金幣、進度）保存在各人的瀏覽器裡，互不影響

## 🎯 遊戲內容

- **5 個關卡**：公園草地 → 黃昏市場 → 夜色住宅區 → 倉庫工地 → 深夜市中心
- 每關約 6 分鐘：一路打怪升級，5:00 出現 **Boss**，擊敗即過關並解鎖下一關
- **5 隻貓咪**：橘寶、雪球、黑炭（免費）＋ 花花、阿虎（金幣解鎖）
- 升級到 Lv5 / Lv15，貓咪會**進化**（戰貓 → 傳說貓神）
- **8 種武器**＋6 種被動，武器滿級且角色 Lv12 後可**進化武器**
- **金幣商店**：永久強化（生命、攻擊、速度、冷卻、吸取、幸運、金幣、復活）
- 破完 5 關解鎖 **無盡模式**；排行榜與各關紀錄存在本機

## 📚 複習模式（走動＝出題・答對＝升級）

主選單點「📚 複習模式」：攻擊全自動，你只要移動走位；**走動累積到一定程度就會自動出題**，答對才能升級道具！

- 🚶 走動約 10 秒（累積移動距離）自動彈出一題；站著不動不會出題
- ✅ 答對 → 三選一升級道具（武器／被動），連擊 +1
- ❌ 答錯 → 顯示正解，獲得安慰獎（回血 20%＋5🪙＋5 秒護盾），連擊歸零
- 🔥 連對 3 題（3 的倍數）→ 額外 +15🪙＋3 秒無敵
- ⬆️ 角色進化改成「答對 5 題／12 題」觸發；經驗寶石改成掉金幣
- 結算畫面有 **答題成績（正確率）＋錯題複習清單**，下課直接複習！
- 內建 53 題：第一次段考選擇題 22＋閱讀題組 6＋是非題 20＋註釋 5（皆含正解）

### 想換成別的題目？
用記事本打開 `index.html`，搜尋 `const QBANK = [`，每題格式如下：

```js
{ tag: '第一次段考・選擇 1', q: '題幹文字', opts: ['選項A', '選項B', '選項C', '選項D'], ans: 0 },
```

- `tag`＝題目來源標籤（顯示在題目卡上）、`q`＝題幹、`opts`＝選項
- `ans`＝**正解是第幾個選項，從 0 開始算**（上面例子正解是選項 A）
- 選項放 2 個 → 顯示「○／×」是非題；放 4 個 → 顯示 ABCD 選擇題
- 可選欄位：`note: '補充小字'`、`passage: '閱讀文章全文'`（閱讀題組用）
- 刪掉不要的題目（整行刪除）、貼上自己的題目，存檔後重新整理即可

## 🧑‍🏫 給老師的小抄（想調整遊戲時）

用記事本打開 `index.html`（不要用 Word），搜尋這些關鍵字：

| 想改什麼 | 搜尋 | 說明 |
|---|---|---|
| 整體難度倍率 | `diff:` | 輕鬆/普通/地獄的敵人血量、數量、金幣倍率 |
| 關卡時間、Boss 時間 | `boss:` | `t: 300` 是 5 分鐘出現 Boss（單位：秒） |
| 開局血量/速度 | `player:` | `hp: 100`、`speed: 210` |
| 怪物強度 | `const EK = {` | 每種敵人的血量 `hp`、速度 `speed`、傷害 `dmg` |
| 每關生怪表 | `const STAGES = {` | `rate` 是每秒生成數量 |
| 複習題庫 | `const QBANK` | 題目、選項、正解（格式見上方複習模式說明） |
| 複習模式出題頻率 | `quiz: { dist:` | 數字愈小出題愈頻繁（1600 ≈ 走動 10 秒一題） |
| 商店價格 | `SHOP_PRICES` | 五級價格 |

改完存檔、重新整理瀏覽器即可生效。
如果角色「無敵閃爍」想關掉，搜尋 `invuln` 把 `0.6` 改小即可。

> 除錯模式：網址後面加 `?debug=1` 會顯示 FPS 與實體數量，按鍵盤 `T` 可 5 倍速測試。
